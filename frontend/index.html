🔐 YouTube cookies (optional)

YouTube often blocks requests from datacenter IPs. To download from YouTube, upload a cookies.txt exported from a browser where you're logged into YouTube. Don't share this file — it contains your session.

How to export cookies.txt
  1. Install the browser extension "Get cookies.txt LOCALLY" (Chrome / Firefox).
  2. Open youtube.com and make sure you're signed in.
  3. Click the extension → Export → save the file.
  4. Upload it below.

Alternative CLI: yt-dlp --cookies-from-browser chrome exports it for you.
